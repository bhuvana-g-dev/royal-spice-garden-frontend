# Royal Spice Garden — Frontend

A modern responsive restaurant website built with HTML, CSS, and JavaScript featuring a luxury dark-themed UI, dynamic menu rendering, category filters, mobile responsiveness, and real-time integration with a Node.js + MongoDB backend.

## Live Demo

🌐 Frontend:
https://royal-spice-garden-frontend.vercel.app

⚙️ Backend API:
https://royal-spice-garden-backend.onrender.com/api/menu

🔐 Admin Panel:
https://royal-spice-garden-backend.onrender.com/admin/login.html

---

## Features

- Responsive luxury restaurant UI
- Dynamic menu loading from MongoDB
- Category-based filtering
- Real-time admin updates
- Mobile-friendly navigation
- Skeleton loading states
- Fallback menu handling
- Contact & booking forms
- Clean animations and transitions
- Public API integration
- Deployed using Vercel + Render

---

## Tech Stack

### Frontend
- HTML5
- CSS3
- Vanilla JavaScript

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication

### Deployment
- Vercel (Frontend)
- Render (Backend)
